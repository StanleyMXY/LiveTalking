# 数字人 Demo 测试手册

适用对象：参与本轮内部测试的同事。本 Demo 用于验证"语音输入 → 大模型回复 → 语音合成 → 数字人口型视频"这条实时对话链路，不是最终产品形态。

## 1. 开始之前

| 项目 | 说明 |
|---|---|
| 测试地址 | 由组织者提供，形如 `https://xxxx.trycloudflare.com/dashboard.html`。每次重新开放测试，地址都会变，请以最新发给你的为准。 |
| 浏览器 | 电脑上的 Chrome 或 Edge。手机浏览器未经验证，如果使用，请在反馈里注明机型和浏览器。 |
| 设备 | 需要麦克风和扬声器（或耳机）。建议戴耳机，避免数字人的声音被麦克风收进去。 |
| 网络 | 能正常访问外网即可。使用 VPN 也可以，请保持 VPN 为全局模式。视频如果在你的网络下直连不通，会自动改走中继服务器，一般不需要额外设置。 |
| 测试语言 | 本轮请使用**中文**。其他语言不在本轮测试范围内。 |

注意：
- 测试地址只发给了测试人员，请不要转发给其他人。
- 页面里没有登录，知道地址的人都能使用，所以请在测试完成后不要再保留或分享该地址。

## 2. 快速上手（5 步）

1. 用浏览器打开测试地址。
2. 点击页面上的蓝色按钮"**开始连接**"。第一次使用时浏览器可能会询问麦克风权限，请选择"允许"。
3. 等待状态从"连接中…"变为"**已连接**"，并看到数字人的画面。"已连接"表示已经收到视频画面。
4. 在"对话模式"下，二选一：
   - 在输入框里打字，点"发送"；
   - 按住"按住说话"按钮说话，松开后发送。
5. 数字人会用声音和口型回复你。**回复内容不会以文字显示在对话框里**，请听声音、看画面。

测试结束后，点击"停止连接"。

## 3. 页面功能说明

### 3.1 连接

| 按钮 | 作用 |
|---|---|
| 开始连接 | 建立与数字人的实时连接。连接后该按钮变成"停止连接"。 |
| 停止连接 | 断开连接，释放服务器资源。不用的时候请断开。 |
| 视频大小调节 | 调整画面显示大小，只影响你自己的页面。 |
| 使用 STUN/TURN 中继服务器 | 帮助浏览器在不同网络之间建立连接，直连不通时通过中继转发视频。默认已勾选，**请保持勾选**。 |

同时在线人数有上限（目前为 5 人）。超出时连接会失败并弹出错误提示，请稍后再试。

### 3.2 对话模式与朗读模式

| 模式 | 你输入的内容会被如何处理 |
|---|---|
| 对话模式 | 把你的话交给大模型，数字人回答你。这是主要的测试对象。 |
| 朗读模式 | 不经过大模型，数字人只是把你输入的文字原样读出来，用来单独检查语音合成和口型。 |

两种模式下，新发送的内容都会打断数字人正在说的话。

### 3.3 语音输入

输入框下方的"按住说话"：
- 按住按钮说话，**松开后才会发送**；
- 说完之后按钮会短暂显示"识别中…"，随后你说的话会出现在对话框里（以"您："开头）。

页面上的"ASR 方式"有两个选项：

| 选项 | 说明 |
|---|---|
| 本地 SenseVoice（默认） | 由服务器识别语音。建议使用这个。 |
| 浏览器语音识别 | 使用 Chrome 自带的识别功能，依赖浏览器自身的在线服务，网络环境不好时可能不可用，且只支持 Chrome。 |

如果提示"无法访问麦克风"，请检查浏览器地址栏左侧的权限设置，允许麦克风后刷新页面重试。

### 3.4 TTS 后端与音色

| 项目 | 说明 |
|---|---|
| TTS 后端 | 选择语音合成方式。默认 `qwentts_cherry`，请使用这个。`cosyvoice_local` 需要组织者另外开启服务，只有组织者明确告知可用时才选它。 |
| 音色 | 选择数字人的声音。默认音色或列表中的任意预置音色都可以试听。 |

TTS 后端和音色可以在连接之后随时切换，对**下一次**发送的内容生效。

### 3.5 数字人形象

页面上有一个形象下拉框，目前内置一个形象。

**重要**：形象是在"开始连接"那一刻确定的。如果想换形象，必须先"停止连接"，选好形象后再"开始连接"。

### 3.6 定制数字人形象（上传照片或视频）

用于用一张照片或一段视频生成你自己的数字人形象。

1. 在"定制数字人形象"里选择文件（图片或视频），填写"形象名字"。
2. 点击"生成形象"，下方会显示进度。
3. 显示"生成完成"后，在形象下拉框里选择新形象，再"开始连接"。

要求与说明：
- **形象名字**只能使用英文字母、数字、下划线和短横线，最长 64 个字符，**不能用中文**。
- 上传文件不能超过 100 MB。
- 图片需要是清晰的、能检测到人脸的正脸照片。检测不到人脸时会提示生成失败，请换一张。
- 用图片生成需要一两分钟，请耐心等待。多人同时提交时任务会排队，一个一个处理。
- 请不要上传包含他人隐私或你不希望被保存的照片，上传的文件会保存在服务器上。

### 3.7 克隆新声音

用于用一段你的录音克隆出一个新音色。

- 这个功能**只在选择 `cosyvoice_local` 后端、并且组织者已开启该服务时才可用**。默认的 `qwentts_cherry` 不支持克隆，点击"克隆"后会显示"失败"，并附一行英文提示（含 `does not support voice cloning`）。
- 上传一段清晰的单人说话录音，填写"名字"（规则同上，只能用英文字母、数字、下划线和短横线）。"文字稿"可以留空，留空时会自动转写，会稍慢一些。
- 克隆成功后，新音色会出现在"音色"下拉框里。

### 3.8 开始录制 / 停止录制

这是服务器端录制本次会话的功能。本轮测试不要求使用。

## 4. 建议的测试内容

请尽量覆盖下面这些场景，并留意体验是否自然：

| 场景 | 观察重点 |
|---|---|
| 连接 | 从点击"开始连接"到出现画面用了多久；是否一次成功。 |
| 日常对话 | 回复内容是否合理、是否答非所问；回复开始前的等待是否可以接受。 |
| 连续对话 | 连续聊 5 轮以上，是否记得上文、是否出现卡顿或断开。 |
| 语音输入 | 识别是否准确；安静环境和有背景噪音的环境各试一次；语速快慢各试一次。 |
| 打断 | 数字人说话时，发送新的内容，是否能及时打断并回应。 |
| 朗读模式 | 读一段较长的文字，声音是否自然、口型是否对得上、有无破音或漏字。 |
| 音色 | 不同预置音色的声音是否自然。 |
| 定制形象 | 用自己的照片生成形象，生成后的画面是否像你、表情和口型是否自然。 |
| 长时间使用 | 连续使用 10 分钟以上，画面和声音是否保持稳定。 |

## 5. 如何反馈问题

请尽量提供以下信息，方便定位：

1. 发生问题的**大致时间**（精确到分钟），便于对照服务器日志。
2. 你的**浏览器**和**设备**，以及你所在的**网络环境**（家里 Wi-Fi、公司网络、手机热点等）。
3. 你做了什么操作，数字人是什么反应，你期望的是什么。
4. 截图或屏幕录制（如有）。
5. 弹窗或页面上出现的**错误文字**，请原样复制。

## 6. 常见问题

| 现象 | 可能的原因与处理 |
|---|---|
| 一直显示"连接中…"，或者没有画面 | 等待约 30 秒。仍然没有画面，先确认"使用 STUN/TURN 中继服务器"是勾选的，点"停止连接"后重新"开始连接"。还是不行，请刷新页面（Ctrl+F5）后再试一次；仍然不行，请换一个网络（例如手机热点）再试，并在反馈里告诉我们你的网络环境和是否开了 VPN。 |
| 点击"开始连接"后弹出错误 | 可能是同时在线人数已满（上限 5 人），稍等几分钟再试；否则请截图反馈。 |
| 有画面但没有声音 | 检查电脑音量和浏览器标签页是否被静音；点一下页面后再试。 |
| 语音识别不出文字，或"无法访问麦克风" | 允许浏览器使用麦克风；确认系统选中了正确的麦克风；尝试把"ASR 方式"保持在"本地 SenseVoice"。 |
| 数字人答非所问或回答不完整 | 属于测试要观察的内容，请记录你的原话和它的回复情况并反馈。 |
| 页面打不开 | 地址可能已经失效（组织者每次重新开放测试，地址都会变）。请向组织者索取最新地址。 |
| 生成形象失败 | 换一张更清晰的正脸照片；名字里不要含中文或空格。 |

## 7. 已知限制

测试时遇到下面这些情况，是目前就存在的，不需要作为新问题反馈（但如果你觉得影响很大，也欢迎说明）：

- 数字人的回复**只以声音和画面呈现**，对话框里不显示回复文字。
- 视频如果经由中继转发，延迟会比直连略高。
- 本轮只验证了中文，其他语言的识别、回复和发音效果尚未验证。
- 同时在线人数有限，多人同时使用时可能感觉变慢。
- 测试地址在每次重新开放时会变化。
